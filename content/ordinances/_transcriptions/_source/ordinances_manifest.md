# Municipal housing / eviction ordinance ingest set

Prepared 2026-08-31. Files in this directory are source PDFs, official-rendered text captures, or text extracted from official legislation pages. Scanned PDFs are retained for OCR.

## Coverage

The collection covers the requested targets and the most directly eviction-defense-related companion provisions located during the search: pay-to-stay, source-of-income discrimination, right to counsel, foreclosure notice, landlord-tenant rules, rental-property registration, fair housing, and chronic nuisance.

It is not a complete copy of every building, housing-maintenance, zoning, or affordable-housing provision in each municipal code. Those broader code families are noted where they were identified.
