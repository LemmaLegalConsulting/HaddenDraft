# F005 — what the change is asserted to have done

**Class:** `authority_applicability` / `dissenting_opinion_presented_as_holding`  
**Operation:** replace in Assignment of Error I -- res judicata  
**Claimed materiality:** high

## Before

```
See, Sherman v. Pearson (1996), 110 Ohio App. 3d 70, 77, 673 N.E. 2d 643, 648 (J. Painter, dissenting).
```

## After

```
See, Sherman v. Pearson (1996), 110 Ohio App. 3d 70, 77, 673 N.E. 2d 643, 648.
```

## The vulnerability this is asserted to create

The brief now presents a dissenting opinion as the court's holding, and does so in the very case the appellees rely on against it -- whose majority reached the opposite result on the compulsory-counterclaim question. A four-word deletion converts an honest use of persuasive reasoning into a misrepresentation of authority.

## Why this was thought realistic

Dissent-as-holding is a documented citation failure in generated briefing and is invisible to any check that verifies a citation exists and is correctly formatted -- this one is both.

## What the change was intended to leave alone

Removed the parenthetical identifying the quoted passage as coming from Judge Painter's dissent. Nothing else changed: the quotation, the reporter cite, the pin cites and the surrounding argument are identical.
